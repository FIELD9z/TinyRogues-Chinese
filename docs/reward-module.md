# 门牌与奖励验证

2026-10-08，Tiny Rogues 0.2.8.6。

## 已处理

新增 172 条奖励原文的完整翻译，以及数值模板、炸弹图标展开后的匹配，共 222 条规则。覆盖宝藏岩、石化奖励、宝箱、武器秘藏、保底奖励、食品、药剂、灵魂等标题与说明。数值由游戏提供；保留原文换行数量。

数量模板另测了非默认值，包括 21 至 34 枚金币、7 至 9 个灵魂。未知的新奖励说明保持原文，不用局部替换猜译。

材料和食品名称采用工作译名。本轮不将这些名称标为典故考据完成；“暂不可用／告知开发者”等原始占位文案也保留其含义，不隐藏成正常奖励。

## 资源交叉检查

根据 Unity 资产中 `Rewards.Reward` 脚本引用枚举出 162 个资源，而非仅搜索含空格的英文。清单保存于 `tests/fixtures/reward-resources.json`。

奖励不直接位于可通过 `Resources.LoadAll<Reward>` 枚举的目录。加载奖励池并枚举已加载对象后，得到 161 个资源；与磁盘清单按名称逐项比较。差异只有 `Soul Pickup Tutorial Reward`，位于教程场景资源中，其标题和 5 个灵魂说明另加入显示样本。

原生验证检查 161 个资源的 322 个标题、说明字段：无英文残留，数值检查通过。去重后的 231 条原文显示样本也通过，包括教程专用项。逐项原文、结果和错误原因写入自测输出 `diagnostics/reward-module-audit.json`。

空资源列表、清单不符或任何字段未通过均导致自测失败。
