# 交互状态回归

2026-10-12，Tiny Rogues 0.2.8.6。

本轮依据实际游玩日志和截图修复：

- 装备菜单的使用、装备、丢弃、交换、取消选项，覆盖普通、选中、彩色与灰色状态。
- 篝火的获得恩赐、完全恢复、灵魂费用及说明；进入下一层与楼层出口提示。
- 套装秘藏、使用钥匙、军械库与精良武器说明，以及同次日志中的酒馆提示。
- 世界阶层升级提示，阶层数字与颜色使用参数。
- 包含不换行空格的精通标题，包括最后关头、幸运开局和备用军械库。

## 原因

选中项会在原文前添加 `> `，颜色标签中还可能包含这个符号；原来的完整标签规则未覆盖这一结构。精通标题则会把普通空格替换为不换行空格，导致已有译文无法匹配。游戏的关键词着色还可能进一步拆开原文。

已知短标题和选中项在原生排版前处理，箭头、颜色与图标保留。特殊空格仅用于已知短标题的完整匹配，未知文本保持原文。装备整段说明不提前走这条处理路径。

军械库门牌和篝火选项没有被上一轮的 `Rewards.Reward` 资源清单涵盖。奖励资源的检查数字不能作为整个门牌或交互系统的覆盖率。

## 验证

`tests/fixtures/interaction-states.json` 保存 54 个实际或组合状态。核心检查译文、标签顺序、未知选项保留，以及不同阶层数字和颜色。原生测试分别通过 TMP 直接赋值和游戏排版入口验证；直接赋值路径额外检查选中箭头。

原生回归同时检查特质、奖励、武器、装备和教程，避免界面匹配规则影响说明生成。本轮曾发现提前处理整段文本会导致六件装备出现漏译，缩小处理范围后复测为零；有回归的中间版本未安装。

仍需游玩复核实际位置与换行。特殊门完整交互流程、其他篝火分支及未触发的操作选项尚未全量验收，继续保留在模块待办中。
