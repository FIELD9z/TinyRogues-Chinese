# 翻译覆盖交叉检查

2026-10-05，游戏 0.2.8.6。

## 检查方法

对照原版英文资源、已安装旧词库的英文匹配键，以及新版实际游玩产生的 `missing.jsonl`。匹配检查直接调用本项目 C# 目录，包含上下文、完整样式标签和有限模板。

旧词库仅用于发现可能遗漏的英文，不导入旧中文。补充译文按原版英文重新编写。

旧主词库有 5,364 个英文键，其中 3,916 个能逐字符对应当前原版候选资源。新版可匹配其中 2,026 个；另 1,890 个尚无直接匹配。这个差额包含库错误、资源名称、调试内容、旧拼接方式和组件模板，不是实际画面的漏翻数量。格式变化也可能使两套匹配键不同。
