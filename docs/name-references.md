# 名称审校记录

核对日期：2026-10-05。来源确认以物品页面的 Trivia 为依据；原作品的中文译名存在版本差异时，记录所选版本。没有直接出处证据的条目保留说明，不把译名选择写成作者意图。

| 原文 | 当前译名 | 审校结果 |
|---|---|---|
| Gimmershred | 寒铁飞刃 | 页面明确引用《暗黑破坏神》同名武器。采用 D2R 简体名称；旧版中文“碎片贪婪者”和 D2R 繁体“吉默削斧”也是版本译名。“碎光”不再使用。 |
| Punk Hazard | 庞克哈萨德 | 页面明确引用《航海王》同名岛屿。采用常见中文地名，不再逐词翻译成“朋克危机”。 |
| Buster Blade | 破坏剑 | 页面明确引用克劳德的武器 Buster Sword。采用常见中文名；“毁灭剑”也是已有译法。 |
| Chloroblast Bow | 叶绿爆裂弓 | 页面说明旧名 Chlorophyte Bow 引用《泰拉瑞亚》叶绿系列。保留叶绿意象，同时译出当前英文 blast。并非照搬一个不存在的原作弓名。 |
| Gunchaku | 枪节棍 | 保留 Gun + Nunchaku 的双关解读，游戏效果支持旋转并射击。译名定稿；词源是语言和机制推断，页面未直接声明。 |
| Ex Mortis | 亡者之书 | 修正“前世死亡”。游戏资源确认魔法书类别；疑似《鬼玩人》的 Necronomicon Ex-Mortis，尚无直接出处证据，中文暂用自然意译。 |
| Fidget Glaive | 指尖战刃 | 修正“坐立不安战刃”。疑似指尖陀螺意象，但未取得物品页面 Trivia 或图标证据，译名暂定。 |
| Quecholli | 重击之锤 | 采用《流放之路》同名武器的简体名称。原生资源确认锤类和爆炸效果，与同名武器吻合；未取得 Tiny Rogues 的直接出处说明，来源仍为推断。 |
| Nimbus Cloud | 雨云 | 采用字面中文名称，修正“雷云云”。页面 Trivia 为空，筋斗云典故尚未确认。 |
| Cloak Of Mystra | 密斯特拉斗篷 | 统一 Mystra 的中文专名并调整语序。“密丝特拉”也是已有译法；页面未直接声明作品出处。 |
| Megingiard Belt | 梅金吉奥德腰带 | 采用北欧神话腰带的已有音译。游戏拼写和力量效果支持来源判断，但没有明确 Trivia。原先停用的名称条目现已启用。 |
| Ring Of Royal Grandeur | 皇家华戒 | 暴雪中文公告提供原作品中文名；游戏名称及套装效果支持引用判断。页面 Trivia 为空，出处属于强推断。 |
| Pouchy Robe | 口袋长袍 | 结合袋状含义和额外药瓶容量定稿。“袋装长袍”语义不当；未发现明确作品出处。 |

## 定稿范围

此前列出的 13 个名称均已处理：10 个译名定稿，Ex Mortis、Fidget Glaive、Quecholli 三个改为自然中文暂译，仍保留来源待核说明。译名定稿不表示每个典故都已取得作者或物品 Trivia 的直接确认。

词库校验及 102 项回归检查通过。隔离游戏副本的原生检查通过：2,103 个不同汉字具备字形；397 个中文武器名称及保留原码的 VBFG、398 张武器卡片、645 张装备卡片完成生成检查。名称考据不证明全游戏覆盖或所有排版均已检查。词库仍有 50 条停用待审条目。

本次记录针对之前列出的名称疑点，不代表全部名称都已经过典故审查。缺失红心、伤害取值等机制待审条目不因名称考据而启用。
