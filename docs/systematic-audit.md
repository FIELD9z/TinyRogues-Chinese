# 文本系统核查

2026-10-06，Tiny Rogues 0.2.8.6，运行时词库 5,799 条。

此前检查依赖筛选后的源文和选定的运行样本，不能证明全部教程或旧插件内容已覆盖。本轮重新登记来源，并对合并清单中的每个输入生成检查结果。源文、来源、上下文、匹配输出、残留字母、数值和图标检查分别保存；原生调用、译义及排版保留独立状态。

## 来源范围

- 完整枚举 IL2CPP 声明的 17,876 条字符串记录，其中 17,017 条含 ASCII 字母。
- 检查 9 个 Unity 序列化文件，包括 `level0/1/2`，涉及 100,963 个对象。提取 316,322 条字段或长度前缀候选。
- 旧词库 7 个文件共 9,106 条源文。此前因未闭合 `<` 未能解析的 4 行已恢复，原有 9,102 条源文比对一致；空行和注释也有逐行记录。
- 合并历史游戏提取、当前运行捕获、原生测试输入、旧规则样本以及当前词库全部记录，停用词条也保留。

共 516,616 个来源记录，合并为 115,546 个检查项，涉及 64,304 个不同原文，其中 63,124 个含可见拉丁字母。原文没有 trim、改写或按长度静默删除。所有检查项都有结果，所有来源记录都有对应项。

这些数量包含同一原文在多个入口的记录、技术字符串、格式串和逐字显示中间态，不是玩家可见漏翻数量，也不是汉化完成率。4 项数值待查对应同一版本号字符串：检测器把 `Pre-0.2.8` 的连字符当成了负号，需要按语义复核，不能直接判断译文改坏了数值。

另有 569 个不同源文在记录或推定的对话入口未匹配。旧对话文件中含片段和其他用途的字符串，须确认生成入口后再处理。实际捕获未匹配候选有 1,870 项；此视图省略已知的严格前缀，前缀仍完整保留在总台账中。若同一源文在上游入口已有翻译，记录关联入口作为调查线索，不据此认定当前入口已通过。

## 未验证范围

40,807 个 Unity 对象无法按字段结构读取。失败对象、文件位置和错误均已登记，原始字节候选仍保留。字节扫描要求可打印 UTF-8、含 ASCII 字母且长度不超过 4 MiB，不能据此证明未知编码或其他二进制内容没有文本。

文件级清单还记录了 20 个未解码文件及原生代码分支。动态拼接、条件组合、设备切换、图片中的文字和真实页面排版仍需验证。当前运行捕获还限制文本长度、连续字母长度和单次去重数量，不能作为全量来源。

历史原生样本只附在对应输入或规则上，先核对输入和插件快照哈希。历史证据不会升级为当前版本或正常游玩通过。本轮未运行全游戏逐条实机验证，也没有完成所有译义审校。

## 复核方式

[核查工具](../tools/audit/README.md)输出完整 JSONL 台账、可读对话候选清单和来源问题 manifest。报告生成时检查输入及结果哈希，逐项核对全部原始字段，并复核旧词库每个物理行。测试覆盖短字母、混排、空白、长文本、未知上下文、无效正则、模板和过期结果拒绝。

大型原文与运行数据仅保留在本地。后续修正应引用台账 ID 和来源，并分别补充静态、原生、译义与排版证据；尚不能翻译或触发的内容继续保留原因，不从统计中删除。
