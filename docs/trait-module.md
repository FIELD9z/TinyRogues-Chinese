# 特质模块验证

2026-10-07，Tiny Rogues 0.2.8.6。

## 修复范围

- 在 `Trait.Description` 生成说明时，临时翻译特质和关联效果的文字，生成后恢复资源字段。
- 对生成后的完整句子应用数值模板。数值仍由游戏计算；未知效果名称不猜译。
- 处理嵌套颜色、图标、项目符号及周期、增益、情绪标签。
- 将伤害掷骰说明中的 `twice`、`lower` 作为普通文字翻译，而非保护为变量。
- 补充特质重掷概率、幸运与幸运命中提示。
- 修复技能冰冷伤害、爆炸附加火焰伤害的数值区间语序，以及阵营上限的倍率措辞。

## 验证

隔离游戏主动加载全部 146 个特质，分别调用普通和详细说明，共 292 项。逐项保存原始英文、生成后的中间文本、最终显示文本与错误原因；检查英文残留、数值是否改变、特质原始说明是否恢复。初轮有 134 项未通过，修复后为 0 项。

`diagnostics/trait-module-audit.json` 是运行自测生成的逐项记录。资源数为零或存在未通过项时，自测失败；不会把没有检查到的内容当作通过。

核心回归包含独立数值、未知效果、伙伴数量、颜色标签、嵌套说明和数值区间语序。新增三条关联界面样本后，原生界面回归共有 389 条。

## 验证边界

292 项是默认诊断状态下的普通、详细说明，不是 292 种游玩状态。自动检查无法证明所有角色组合、局内增益、窗口尺寸和换行效果正确。中文全文已逐项查看，但名称典故与跨模块术语仍以独立审校记录为准。

当前状态为“自动验证通过，待游玩复核”。门牌、角色面板其他属性、其他对话按各自模块继续处理，不算进本模块的通过数字。
