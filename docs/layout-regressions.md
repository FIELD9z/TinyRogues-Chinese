# 酒馆对白与中文排版回归（2026-10-13）

本轮依据五张游玩截图与对应运行捕获，处理装备负重惩罚、环境对白、三段酒馆收费对白，以及横排选项和说明段落排版。

## 原因与修复

- 酒馆节点在已有整段对白后追加带颜色、数值和金币图标的价格，导致完整匹配失败。现在仅在整段正文已知、价格后缀符合原生格式时组合翻译；保留价格、颜色和图标。
- 中文回退字形的实际换行与 TMP 的首选宽度不一致，横排 `>是<` 的末尾箭头会落入下一行。仅对原生两个横排控件的短中文选项禁用自动换行；隐藏对话或复用为英文、多行、长选项时恢复原设置。
- 部分说明段落的实际字形高度超过 TMP 的首选高度，另一些段落缺少足够的字形边界留白。仅为 TextBox 内的中文正文段落记录实际行高，下一帧请求重新布局，并补充与字号成比例的段间留白。按文本、宽度、字体、字号、间距等条件验证缓存，销毁控件时清理。

## 验证范围

- 16 条本轮完整运行捕获，经与插件相同的翻译入口检查；测试价格、颜色、按键变化及未知正文拒绝匹配。
- 核心测试 2,103 项通过；46 个词包、8,528 个生效条目。
- 独立游戏副本中复用原生 TextBox，对 2,150 条武器、装备、技能、形态和收藏品等说明样本追加第二段校验文本。修复前 6 条出现负段间距，1 条实际高度超出布局高度；修复后两项均为 0，最小段间距约 3.438 个布局单位。
- 样本来源包含先前生成的卡片原文与模块审计译文，衡量的是排版，不能据此宣称所有原生对象的翻译覆盖率为 100%。
- 原生对话探针对比英文基线、中文是/否、交谈/离开、收费留宿对白、多行正文和两段说明，并检查控件复用时恢复换行。离屏图像使用原生画布或实际 TMP 字形网格，未手工重画文字。
- 完整原生自测通过：46 条实际界面样本、29 条对白/教程逐字显示样本、2,204 个中文字符字形；同时复查原有模块、描述字段恢复及数值保留。构建仍有既有 BepInEx 引用版本警告，没有编译错误。

可复现探针见 `tests/native-probes/layout-probe/README.md`；六条已发现的问题样本保存在 `tests/fixtures/layout-regressions.json`。全量诊断输出含本地运行数据，不随安装包发布。

此验证针对已复现控件及样本，不代表已经人工遍历所有游玩场景、字体设置和窗口尺寸。
