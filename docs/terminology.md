# 术语基线

武器与装备专名的定稿、版本译名差异及仍待核对的出处见[名称审校记录](name-references.md)。

风格是“机制准确、中文自然”。以下是当前维护基线，专有名词及梗的译名仍可根据原始文本和机制证据调整。明确区分系统概念，不以同一个汉语词合并两种机制。

| English | 中文 | 使用边界 |
|---|---|---|
| Strength / Dexterity / Intelligence | 力量／敏捷／智力 | 三项核心属性。 |
| Power | 威力 | 与 Strength“力量”区分；武器伤害相关数值。 |
| Tick Speed | 结算频率 | 周期性效果的结算快慢；具体效果仍按原始说明判断。 |
| Trait | 特质 | 局内特质系统。 |
| Skill | 技能 | 主动技能系统。 |
| Perk / Mastery Perk | 天赋／精通天赋 | 与特质和临时增益区分。 |
| Mastery | 精通 | 局外成长相关。 |
| Equip Load / Capacity | 装备负重／负重上限 | 区分当前负重与允许上限。 |
| Damage Scaling | 属性补正 | 力量、敏捷、智力对武器伤害的补正等级。 |
| Attunement / Infusion / Enchantment | 调谐／灌注／附魔 | 三种不同系统。 |
| Alignment | 阵营倾向 | 路线与立场语境。 |
| Mana | 法力 | 技能资源。 |
| Stamina | 体力 | 冲刺等动作消耗的资源。 |
| Burn / Scorch | 燃烧／灼烧 | 分别保留两个原始状态名称。 |
| Missing Heart / Armor | 缺失红心／护甲 | 保留原文的缺失量含义，不直接解释为治疗或修复。 |
| Flask / Potion / Booze | 药瓶／药剂／酒水 | 区分使用方式和物品类别。 |
| Tipsiness | 醉意 | 酒水相关上限或数值。 |
| Fire / Burn | 火焰／燃烧 | 伤害类型与状态。 |
| Cold / Chill | 冰冷／寒冷 | 伤害类型与状态。 |
| Lightning / Shock | 雷电／感电 | 伤害类型与状态。 |
| Charm | 护符／魅惑 | 物品类别与状态分别处理。 |
| Luck / Lucky Hit | 幸运／幸运命中 | 属性与命中体系分别处理。 |
| Increased / More | 提高／更多或乘算提高 | 根据实际公式确认加算与独立乘算，不能仅凭英文词猜测。 |

## 研究资料与使用方法

- [Tiny Rogues 官方商店页](https://store.steampowered.com/app/2088570/Tiny_Rogues/)：确认系统名称和游戏定位。
- [官方 Steam 公告列表](https://steamcommunity.com/app/2088570/announcements/)：查找具体版本机制变化；在 PR 中引用相关具体公告，避免只引用列表。
- [社区 Wiki：Game Mechanics](https://roguepedia.net/w/Game_Mechanics)、[Items](https://roguepedia.net/w/Items)、[Traits](https://roguepedia.net/w/Traits)、[Skills](https://roguepedia.net/w/Skills)、[Mastery Perks](https://roguepedia.net/w/Mastery_Perks)：帮助理解语义和系统边界，可能落后于版本，不替代游戏原始文本。
- [中文玩家基础介绍](https://game.3loumao.org/138709183)、[人物介绍](https://game.3loumao.org/62086805)：观察常见表达，不复制段落或中文词库。

这些页面是研究入口，不是本项目已有译文逐条审定的证明。记录考据时应保存具体物品／机制、访问时的游戏版本及原文依据。
